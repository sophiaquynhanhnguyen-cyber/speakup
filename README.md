# Speak Up

Web app luyện nghe nói tiếng Anh mỗi ngày (~40 phút): nghe chép, shadowing, luyện phản xạ, nói tự do (4-3-2), cụm từ, câu chuyện bản thân, theo dõi tiến độ, và hội thoại bằng giọng với AI (cần Anthropic API key riêng).

Dùng tốt nhất trên Chrome hoặc Edge. Dữ liệu chỉ lưu trong trình duyệt của bạn.
